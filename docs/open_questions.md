# 待决策问题

这些问题目前没有最终答案，后续实现时必须通过实验、原型或 ADR 明确记录。

## 首脑层

- 首脑层连续航迹输出的最终损失权重如何设置？
- 解析教师和仿真教师在不同场景下的选择标准是什么？
- 航迹与武器两个头在 PPO 中的优势和 loss 权重如何标定？
- 首脑 MoE 的专家规模和任务映射如何通过实验确定？

## 执行层

- 航迹跟踪奖励中能量、平滑性和误差项的权重如何标定？
- 执行层 route encoder 使用 GRU、Transformer 还是更轻量结构？
- 不同长度航迹窗口的 padding 和 mask 规则如何固定？
- 执行层在正式推理中的 SafetySupervisor 覆盖率阈值是什么？

## 仿真和平台

- ZK 协议字段和本地 JSBSIM 状态的最终映射表是什么？
- 中距弹和近距弹哪些参数直接迁移，哪些需要重新标定？
- 雷达噪声、延迟、丢失和队内通信如何设定？
- custom 初始化覆盖字段和校验规则是什么？

## CFC

- 反事实替换单架任务还是双机协同关系？
- 未来结果预测使用威胁场、进攻场、团队回报还是多任务输出？
- CFC 何时从分析器升级为首脑训练辅助优势？
- 如何验证计划贡献的符号和排序？
- 如何处理诱导、支援和夹击中的联合贡献？
